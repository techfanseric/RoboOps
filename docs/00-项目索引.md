# RoboOps - 机器人商业运营平台

整理日期：2026-07-05

## 项目命名

- 英文名：RoboOps
- 中文名：机器人商业运营平台

## 一句话定义

RoboOps 是面向机器人、自动化设备与具身智能商业落地场景的运营管理平台，用来把“点位、设备/机器人、商品/服务流程、订单、支付、异常、人员角色、运营任务、数据看板”串成一套可复制的标准系统。

## 当前判断

RoboOps 的第一批落地场景包含饮品/咖啡/奶茶亭，产品方向聚焦更通用的机器人商业运营平台：

- 从“设备管理后台”升级为“商业运营平台”。
- 从“给客户 API”升级为“给客户可直接运营的系统”。
- 从“按客户定制”升级为“多场景可配置的标准产品”。
- 从“客户组织自行摸索运营”升级为“平台提供可落地的运营方法和系统能力”。

## 统一口径

当前所有文档按以下口径理解：

- RoboOps 是机器人商业运营平台；饮品亭是第一批样板场景之一。
- 本期 MVP 的目标是搭出可配置框架，并跑通一条真实经营闭环，不追求完整行业中台。
- 客户组织大概率没有成熟商业运营团队，因此系统需要提供团队搭建、角色模板、权限模板和异常分派建议。
- 关键运营问题由 RoboOps 先给默认方案，再让客户方基于事实和组织能力做选择。
- 多租户、多品牌、多场景应在数据模型和权限模型中预留；MVP 界面可先支持少量客户、少量品牌和少量模板。
- 术语上优先使用“点位/场景单元”“商品/服务”“订单/服务请求”“异常/事件”“任务/工单”，将“门店、饮品、配方”等场景语义放入模板和展示配置。
