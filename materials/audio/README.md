# Audio Archive

Store compressed speech recordings here when source audio is available.

Preferred business format:

- Container: `.m4a`
- Codec: AAC-LC
- Channels: mono for speech
- Bitrate: 64-96 kbps
- Sample rate: 44.1 kHz or 48 kHz

`.m4a` is preferred because it is compact, widely playable on phones and desktops, and suitable for meeting/interview archives. `.opus` is acceptable for browser-first capture or very low bandwidth storage, but use `.m4a` as the default archive handoff format unless the capture system only produces Opus.
